# AI_USAGE.md

This project was built with AI assistance. Disclosing per ETHGlobal-style transparency norms.

## Tools used

- **Claude Code (Anthropic CLI)** — codebase navigation, code authoring, design discussion, planning
- **Local research subagents** — verifying Arcium SDK behavior against `arcium-hq/examples` repo and docs.arcium.com
- **arcium init scaffold** — generated by Arcium CLI, not hand-rolled

## What AI did

- Wrote the four Arcis circuits in `encrypted-ixs/src/lib.rs` (init_org_registry, register_profile, intra_org_match, cross_org_match)
- Wrote the Anchor program in `programs/kindred/src/lib.rs`
- Wrote the React/Vite frontend in `app/`
- Wrote the synthetic CODIS profile generator in `data/synthetic-profiles/generate.ts`
- Wrote all docs in `docs/` (this file, ARCHITECTURE.md, CIRCUIT_DESIGN.md, THREAT_MODEL.md)
- Wrote the blog post manifesto

## What AI did NOT do

- The product idea, framing, target populations, and federation primitive design were directed by the human builder.
- All architecture decisions (BUCKET_SIZE=8, IBS over 20 STRs, mutual-consent reveal, federation as the load-bearing claim) were chosen by the human and verified by AI research.
- The naming, tagline, demo personas, and submission narrative are the human's choices.

## Verification process

Every non-trivial claim about Arcium SDK behavior was verified against:
- `github.com/arcium-hq/examples` source code
- `docs.arcium.com` (verbatim citations included in research outputs)
- The `cargo check` and `arcium build` outputs

Hallucinations encountered and corrected during the build:
- Initial version pins (0.8.0) were stale — corrected to 0.9.7 after verification
- Initial install URL `arcium.com/install` was wrong — corrected to `install.arcium.com`
- Initial Arcium.toml schema (`cluster_offset`, `recovery_set_size`) was outdated — replaced with current `[localnet]` block schema

## Design pivots (recorded for honesty)

- **On-chain → off-chain circuit storage.** Original plan uploaded all 4 compiled `.arcis` (9.22 MB) into Solana `comp_def` accounts: rent ≈ 64 SOL. Switched to Arcium's documented off-chain path (`CircuitSource::OffChain { source: URL, hash: SHA-256 }`) hosted on the project VPS at `https://kindred.gudman.xyz/circuits/`. Total comp_def rent drops to ~0.02 SOL across all 4. Integrity is preserved: Arx nodes hash the fetched bytes and refuse the computation on mismatch. See `docs/ARCHITECTURE.md` → "Circuit storage" for the full flow and the judge-verification recipe.
